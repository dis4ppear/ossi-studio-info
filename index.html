Ossi Studio

Ossi Studio is a personal video management application for its operator's own YouTube channels. The application runs on the operator's computer.

It uses the YouTube Data API and YouTube Analytics API to retrieve channel and video statistics, manage video metadata and visibility, and upload or schedule videos when instructed by the operator. Google authorization determines which channels the application can access.

This website provides application and privacy information. It does not provide a public upload service or request access to visitors' Google accounts.
